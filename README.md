## A regra de ouro

> GPT-5.5 e Opus 4.7 são os arquitetos e revisores. **DeepSeek V4 é o executor barato.**

| Modelo          | Papel                                       | Uso     |
| --------------- | ------------------------------------------- | ------: |
| **DeepSeek V4** | Executor — código, testes, refatoração, docs | **70%** |
| **GPT-5.5**     | Arquiteto — planeja, revisa, debug difícil   | **20%** |
| **Opus 4.7**    | Designer — UX, criatividade, decisão final  | **10%** |

- Devs que já usam um modelo de IA mas acham caro ou lento
- Freelancers e tech leads pequenos que precisam reduzir gasto sem perder qualidade
- Quem quer aprender a "delegar" entre modelos como faria com um time de devs
