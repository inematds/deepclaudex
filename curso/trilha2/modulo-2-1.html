🛠️ Setup do ambiente

1

📦 Instalar Claude Code

CLI oficial da Anthropic que roda Opus 4.7 no terminal, com acesso direto a arquivos e historico persistente.

⚡ Comandos

npm install -g @anthropic/claude-code
claude auth login
claude --version

Login via OAuth abre browser. Sem chave API direta — Claude Code gerencia internamente.

2

🎨 Configurar Cursor (ou VS Code + extensao)

Cursor tem dropdown nativo com modelos. Em VS Code, use Continue.dev ou Cline. Configure os 3 modelos como atalhos.

⚙️ Cursor settings.json

{
  "models": [
    {"name": "DeepSeek V4", "provider": "openrouter",
     "model": "deepseek/deepseek-coder-v4"},
    {"name": "GPT-5.5", "provider": "openai",
     "model": "gpt-5.5-2026-01"},
    {"name": "Opus 4.7", "provider": "anthropic",
     "model": "claude-opus-4-7"}
  ]
}
3

🌐 Criar conta OpenRouter

OpenRouter agrega modelos de varios providers em uma so chave. Util principalmente para DeepSeek, que nao tem CLI nativo.

🔗 Passos

  1. Acessar openrouter.ai e criar conta
  2. Adicionar credito ($10 e suficiente para 1 mes)
  3. Gerar API key em /keys
  4. Configurar limite mensal de gasto
  5. Testar com curl: curl -H "Authorization: Bearer $KEY" https://openrouter.ai/api/v1/models
4

🔑 Variaveis de ambiente

Vazar chave por descuido (no git ou em log) custa dinheiro real. Setup correto desde o dia 1.

🔒 Padrao seguro

# em ~/.zshrc ou ~/.bashrc
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
export OPENROUTER_API_KEY="sk-or-..."

Sempre adicione .env ao gitignore. Use direnv para escopo por projeto.

⚠️ Nunca

  • ✗ Hardcode da chave em codigo-fonte
  • ✗ Chave em commit (mesmo apagada do HEAD — fica no historico)
  • ✗ Chave em screenshot publico
  • ✗ Compartilhar chave via Slack/Discord
5

⚙️ Modelo padrao por contexto

Quando o modelo padrao e o barato, voce escolhe os caros conscientemente — economia automatica.

🎯 Configuracao recomendada (Cursor)

  • • Modelo padrao: DeepSeek V4 (atalho: tab)
  • • Cmd+Shift+P: GPT-5.5 (atalho: "Plan")
  • • Cmd+Shift+O: Opus 4.7 (atalho: "Polish")
6

✅ Teste de fumaca

Validar antes de tentar fluxo complexo evita 1h de debug por chave errada.

🧪 Smoke test em 5 minutos

  1. Pedir "fatorial em python" para os 3 modelos
  2. Comparar resposta (todas devem funcionar)
  3. Comparar tempo (DeepSeek mais rapido, Opus mais lento)
  4. Comparar custo no dashboard
  5. Validar que hot-keys de troca de modelo funcionam
