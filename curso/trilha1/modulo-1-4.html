🤖 GPT-5.5: tarefas que pedem raciocinio multi-step

Use GPT-5.5 quando o problema exige conectar 5+ pecas: arquitetura de feature, debug de race condition, escolha entre tecnologias.

📋 Casos tipicos

  • •"Desenhe a arquitetura para sistema de notificacoes (push, email, sms)"
  • •"Por que esse pagamento esta falhando intermitentemente?"
  • •"Devo usar Postgres ou MongoDB para esse caso?"
  • •"Refatore esse modulo respeitando as regras X, Y e Z"
2

🎭 Opus 4.7: produto, criatividade e sensibilidade

Opus brilha em copy de landing, microcopy de erro, hierarquia de UI, escolha entre 2 designs e ajuste de tom.

📋 Casos tipicos

  • •"Sugira 3 headlines para esta landing — qual converte mais?"
  • •"Reescreva essa mensagem de erro para ser acolhedora"
  • •"Critique meu wireframe — o que esta confuso?"
  • •"Esses 2 designs estao validos — qual pega melhor o publico X?"

⚡ DeepSeek V4: execucao em volume

Use DeepSeek para criar 12 componentes React parecidos, gerar testes a partir de specs, escrever docstrings, traduzir codigo entre frameworks. Volume e o sweet spot.

📋 Casos tipicos

  • •"Gere componentes Card, Modal, Tooltip com a paleta X"
  • •"Escreva testes para essas 8 funcoes utilitarias"
  • •"Traduza essas rotas Express para FastAPI"
  • •"Implemente exatamente este plano em Next.js"
4

🔀 Tarefas hibridas: como dividir

Tarefas reais sao hibridas. "Cria feature de pagamento" se desdobra em arquitetura (GPT-5.5) + UX do checkout (Opus) + integracao Stripe + testes (DeepSeek) + revisao (GPT-5.5).

🧩 Exemplo: feature "checkout"

  1. GPT-5.5: arquitetura, fluxo de estado, schema de pedido, riscos de pagamento
  2. Opus: copy de cada estado (loading, sucesso, erro 3DS), microcopy de validacao
  3. DeepSeek: componentes Form, integracao Stripe, webhooks, testes
  4. GPT-5.5: revisao com foco em race conditions e seguranca
5

🆘 Quando NAO economizar (tarefas criticas)

Autenticacao, criptografia, calculo financeiro, migracao de banco — pague o premium e use GPT-5.5 ou Opus do inicio ao fim. Um bug em pagamento custa mais que economia de fatura mensal inteira.

⚠️ Areas onde nao usar DeepSeek puro

  • ✗Auth: sessoes, JWT, RBAC, recuperacao de senha
  • ✗Pagamento: calculo de valor, retry, idempotencia
  • ✗Criptografia: hash de senha, tokens, signing
  • ✗Migrations: alteracao de schema em producao
  • ✗Permissions: ACL, RLS, multi-tenancy
